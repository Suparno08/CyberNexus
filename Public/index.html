How to spot a phishing link.

Six habits that stop most scams before they start.

01

Read the real domain

Only the part just before the final dot-ending counts. In paypal.com.secure-login.xyz the real site is secure-login.xyz.

Try the link checker →
02

Watch for look-alikes

paypa1 uses a number one, and rn can pass for m. Scammers register near-copies of trusted names.

Test a suspicious link →
03

Distrust urgency

“Account suspended”, “act within 24 hours”, “you won”. Pressure is a classic phishing tactic.

04

Don’t trust the padlock alone

HTTPS only means the connection is encrypted. Criminals get certificates too.

05

Check how old the domain is

Phishing sites are often days old. A brand-new domain claiming to be a big company is a red flag.

Go direct

Don’t click. Open the official site or app yourself, or type the address by hand.

( FAQ )

Good questions.

Does a clean result mean a link is safe?

No. CyberNexus reads a link’s structure and registration details for warning signs. It can’t see page content or live blocklists, so treat results as a second opinion, and if you’re unsure, don’t click.

Are my files uploaded?

No. A file is hashed inside your browser. Only its SHA-256 fingerprint is looked up (on VirusTotal, when a key is set on the server).

Which tools need the server?

The SSL checker, DNS lookup, security headers, WHOIS lookup and file reputation ask the CyberNexus server to fetch data. The link checker, IP checker, password tester and hash generator run entirely in your browser.

A tool says it can’t reach the server. What now?

Start it with “npm start” in the project folder and open the site at http://127.0.0.1:3000 rather than double-clicking the HTML file.

Is MD5 safe to use?

Not for security. MD5 and SHA-1 can be forged. Use SHA-256 or stronger for anything that matters; MD5 is shown for compatibility with older checksums.
